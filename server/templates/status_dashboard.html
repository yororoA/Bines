MEMORY / TRANSFER

把记忆带到下一台设备

完整记忆包用于备份与迁移，保留数据库里的记忆、会话、关联和状态。记忆库原有的 JSON 导出适合阅读与分析，不能代替完整备份。

迁移包包含私人记忆，请妥善保管。包内不含人格定义、配置、凭据、QQ 网关数据库、自主 Redis 运行状态、媒体及可重建索引；目标设备需另行配置。恢复前先校验，再在停止记忆服务后导入。

1. 校验迁移包python thingking/memory_admin.py inspect-bundle bines-memory.zip
2. 导入到新目录python thingking/memory_admin.py import-bundle bines-memory.zip --target-dir /path/to/new-memory
仅校验，最多 512 MiB；不会导入或覆盖当前记忆。
