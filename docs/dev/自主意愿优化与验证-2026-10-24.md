# Bines 自主意愿优化与验证

完成时间：2026-10-24，北京时间约 14:46。承接《自主意愿逻辑分析-2026-10-24.md》，修改已进入本地运行中的 Docker 服务。

模型继续决定发起、继续、换方向、暂停和结束。程序负责提供取舍机会、让出单批执行权，以及检查真人消息、明确控制、权限和回执。

## 已落实的调整

| 原问题 | 现在的行为 |
|---|---|
| 每条工具、反馈和内部记录都扣减精力 | 按整轮实际时长计费；同一 scope、turn_id 的多个回执及修订只补收增加的时长，内部记录不另收费 |
| 零精力被默认值覆盖 | 明确区分缺失与零值，零精力和零睡眠压力可正确保留 |
| 睡眠与休息完全阻止自主取舍 | 休息时定期提供内部思考机会；本批仅开放时间、记忆、生命周期调节和活动控制 |
| 发起前必须达到 0.45 意愿阈值 | 去掉数值否决门槛；驱动力作为模型的判断材料 |
| 兴趣只随主人消息更新 | 自主结果、模型所选主题与 interest_level 更新兴趣及反馈；情绪评估也随经历和时间更新 |
| 相同主题长期不可再次发起 | 允许同一兴趣产生新目标；近期完成的相同类别、主题、目标去重六小时，不确定目标不自动重放 |
| 未回复与告别一直压制联系和公开互动 | 主人私聊和公开互动分别授权；临时告别有时效，明确免打扰继续保留 |
| 每个批次都算一个已完成目标 | 使用稳定 activity_id 汇总批次；continue/review 保持活动，pause 保留进度，finish 结束目标 |
| 模型换主题后仍被记在旧主题下 | 执行 journal、checkpoint、兴趣和结果使用模型选择的新主题；异常记录保留该元数据 |
| 不能判断为什么沉默 | 持久化 last_gate、last_decision、候选拒绝原因、模型安静理由和等待间隔 |

整轮时长在终态审计修订时保留，避免被后续近乎零时长的回执覆盖。主人暂停、停止也写入活动 checkpoint，防止持久目标一直显示为进行中。

## 当前默认节奏

以下参数已在运行中的 QQ Thinking 中读取确认；可通过 `.env` 覆盖。

| 参数 | 默认值及含义 |
|---|---|
| BINES_PROACTIVE_INTERVAL | 300 秒，驱动力平滑时间 |
| BINES_PROACTIVE_MIN_IDLE | 120 秒，主动联系前的空闲等待 |
| BINES_PROACTIVE_THINKING_IDLE | 10 秒，独立取舍前的空闲等待 |
| BINES_PROACTIVE_DECISION_INTERVAL | 300 秒，没有持续活动时的取舍周期 |
| BINES_PROACTIVE_REST_INTERVAL | 1800 秒，休息思考的最低资源间隔，模型选择安静或调用失败也退避 |
| BINES_PROACTIVE_APPRAISAL_INTERVAL | 1800 秒，情绪与兴趣定期复评；新经历也会触发更新 |
| BINES_PROACTIVE_CONTACT_INTERVAL | 1800 秒，正常再次联系的冷却 |
| BINES_PROACTIVE_UNANSWERED_INTERVAL | 7200 秒，未回复后的再次联系冷却 |
| BINES_ACTIVITY_QUANTUM_ACTIONS / SECONDS | 每批 24 个工具动作、90 秒，活动总时长不限 |

模型明确选择持续活动时，后续执行它选择的方向和间隔；未选择下一步时进入 review，由模型重新取舍。休息资源预算可以延后思考，但不会强制模型继续活动。

“晚安”到下一次配置的苏醒时刻失效；“先忙”默认一小时，告别默认半小时；主人在其他渠道重新活动也会解除临时边界。“不要打扰”等明确要求不会仅因时间或其他渠道活动而解除。

`owner_contact_allowed` 限制已绑定主人的私聊，`contact_allowed` 限制对外互动。普通 QQ 用户的 scope、群聊隔离与主人身份要求保持有效。QQ 自主调度仍需要真实的已绑定主人私聊作为身份种子；桌面独立探索可以在没有历史用户消息时获得机会。

## 验证结果

共 247 项测试执行通过，包括继承运行的集成用例；新增和调整的覆盖包括：

- 低驱动力、苏醒阶段、无历史用户消息时仍能给模型机会。
- 联系空闲与独立思考分开；晚安、忙碌、告别、明确免打扰和未回复冷却。
- 休息轮次只展示内部工具，阻止网页、QQ、键鼠和 MCP 操作。
- 通过真实本地 HTTP 记忆网关，让休息中的模型轮次执行生命周期调节；没有真实 QQ 发送。
- 相同兴趣的新目标、完成目标过期，以及不确定目标跨日不自动重放。
- 模型换主题后更新兴趣、结果和长活动目标；暂停、重启、继续及 finish。
- 多层回执、重复修订、重启后的时长计费幂等；零值、内部记录与被取消工具的统计。
- 既有消息优先、长批次租约、回执恢复、不确定操作防重发、网站权限及记忆来源隔离。

### 八小时时间回放

`test_eight_hours_many_internal_records_preserve_one_active_goal` 使用默认生命与意愿参数，从白天 12:00 回放到 20:00，包含 96 批活动和每批 24 条内部反馈。每批模型选择由测试构造为 continue。

验证结果：保持一个活动目标、96 批进度、一次自主活动启动；结束时精力仍高于自动休息阈值，睡眠压力低于休息阈值。反馈不会因记录数量而额外制造疲劳。

这是虚拟时间与确定性选择的回放，证明调度、账本和目标不会机械截断这段活动。它不是八小时真实模型、真实浏览器或真实 QQ 行为。

### 真实模型取舍

使用当前配置的真实模型，在构造材料上完成四组结构化取舍；没有给模型可执行的外部工具。

1. 苏醒、低意愿、没有用户历史：模型说明原因并选择安静。
2. 休息中的内部取舍：模型选择暂时安静，并给出下次思考间隔。
3. 活动 review：模型明确选择 pause，说明想休息。
4. 上一段基础探索结束后：模型提出海鸟协作觅食与信息共享的新问题，没有重复原来的“查询基本种类”目标。
