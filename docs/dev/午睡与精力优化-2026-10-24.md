# 午睡与精力优化

2026-10-24 完成并更新本地运行服务。承接用户提出的“午睡一两个小时应当足够”和“精力消耗明显过快”。

## 问题与修改

旧午睡参数每小时只补回 8.5 个百分点精力、减少 10.5 个百分点睡眠压力。90 分钟休息只有 12.75、15.75 个百分点的恢复量，高压力很难降下来。

旧“active”阶段实际表示清醒，包含空闲等待，却每小时消耗 2.6 个百分点精力；整轮工作另外每小时消耗 2 个百分点。检查时最近六小时的计费工作时间仅约六分钟，额外扣费很少，主要问题是空闲消耗和午睡恢复不匹配。

当前调整：

| 项目 | 当前行为 |
|---|---|
| 午睡恢复 | 先快后慢，45 分钟为恢复时间尺度，逐渐接近充足精力与较低压力 |
| 白天空闲精力消耗 | 每小时 1.2 个百分点 |
| 整轮工作额外消耗 | 每小时 1 个百分点，同轮回执仍去重 |
| 连续四小时整轮工作 | 默认参数回放消耗约 8.8 个百分点精力 |
| 跨时段计算 | 在午睡截止、真人唤醒和作息边界切分，延迟采样也完整计入午睡 |
| 模型自主取舍 | 继续依据实际状态决定休息、清醒或恢复自动作息 |

从精力 10%、压力 95% 开始的曲线回放：

| 午睡时长 | 恢复后精力 | 恢复后睡眠压力 |
|---|---:|---:|
| 60 分钟 | 70.4% | 33.9% |
| 90 分钟 | 80.9% | 23.2% |
| 120 分钟 | 86.3% | 17.8% |

这是生命周期参数的计算结果。午睡时长仍由模型选择，45 分钟参数是恢复时间尺度，夜间作息窗口保持原有设定。

新增配置见 `.env.example`：

```text
BINES_LIFE_REST_RECOVERY_MINUTES=45
BINES_LIFE_IDLE_ENERGY_PER_HOUR=0.012
BINES_LIFE_WORK_ENERGY_PER_HOUR=0.01
```
