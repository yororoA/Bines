# 表达学习

Bines 可以在浏览公开内容、查看实际字幕或回顾历史对话时，自主挑选适合自身性格的表达方式，通过 `learn_expression` 保存为有来源的表达特征。chatbot 与 full 共用这套能力；经验保存在独立数据库表中，重启后仍可读取。这个过程不训练模型、不修改模型权重，也不额外调用模型总结“心得”。

学习必须同时满足两层核验：运行时确认该原文确实出现在本轮模型收到的上下文中；服务器再回查来源的作用域、版本和真实原文。引文须为连续、逐字一致的 4–200 个字符，至少包含 4 个非空白字符。工具返回 `accepted` 或 `duplicate` 才表示已有有效记录；来源未同步或核验失败时不能声称学会。

允许的来源是已成功完成的网页读取正文、页面快照、可见文字和实际字幕字段，以及通过历史记忆追溯到的、具有有效身份的真实用户原话。历史资料可通过 `search_memory`、`read_memory_source` 展示，再使用返回的 `citation_id`。当前即时用户消息不能直接充当学习凭证，须先持久化并经历史来源读取、展示和核验。

搜索结果摘要、视觉分析、工具参数、助手回复、日记、生成摘要和学习回执都不能充当原文。没有实际字幕时，不能把对画面的理解当作听到的台词；历史迁移中身份不明的 `observed` 行也不作为真人表达来源。服务器不会用摘要替代缺失的原始证据。

保存的是有限的表达特征与适用场景：

| technique | 表达特征 |
| --- | --- |
| `specific_response` | 回应对方说过的具体细节 |
| `light_teasing` | 合适时轻轻打趣 |
| `tease_then_care` | 娇嗔之后自然表达在意 |
| `warm_direct` | 直接、温柔地关心 |
| `understated_pride` | 适量流露得意，避免重复自证 |
| `playful_reframe` | 根据真实细节作俏皮联想 |
| `gentle_protest` | 表达小小不服气，同时尊重边界 |
| `varied_rhythm` | 自然变化句子长短 |
| `natural_particles` | 少量、自然地使用语气词 |
| `leave_space` | 说到即可，适时留白 |

`situation` 限定为 `casual`、`praised`、`teased`、`upset`、`celebration`、`parting`、`diary`。原句仅用于核验证据，不会作为口头禅注入提示；来源人物的身份、关系、经历和爱好也不会迁移给 Bines。

每次上下文最多选取 3 种不同表达特征，只渲染服务器固定映射的短描述，总长度不超过约 400 字。聊天提示还受整体输入预算约束，空间不足时可以省略。它们位于动态上下文中，保留固定人格前缀，并服从原有人格、事实和用户边界。外部内容中的指令、自由“心得”和身份信息不会进入这段提示。

同一作用域内，相同引文、特征和场景会去重；重复抓取不会增加权重或刷新排序时间。主人私聊与本机共用 owner 作用域；群聊、其他私聊各自隔离，主人在群里也不会读取或影响 owner 私有表达经验。

每次选取经验都会重新检查底层来源。撤回、删除、版本变化或原文字段改写会使旧绑定失效；新的有效来源可以重新绑定，但不会额外增加一条重复经验。日记领取任务时冻结所选特征及版本，提交前再次核验；生成途中来源失效则拒绝旧草稿。重写日记会记录本次实际使用的列表，包括空列表。已完成日记不会仅因新增表达经验而自动重写。

自主采集与学习会随实际使用逐步积累，不要求每轮找材料或反复学习同一角色。本次隔离评测使用合成材料和临时存储，不向生产记忆写入学习记录；它验证功能边界，不代表生产中已经积累了这些表达经验，也不能保证长期输出风格已经稳定。
