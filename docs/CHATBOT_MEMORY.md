# ChatBot 当前记忆模式

当前使用本机持久化 SQLite（WAL），默认 `thingking/memory_data/memory.db`，可通过 `.env` 的 `BINES_MEMORY_DIR` 调整。桌面 Thinking 和 QQ Thinking 读写同一数据库；存储共享不等于所有身份可读同一内容。

## 每轮回复读取什么

1. 根据真实 OneBot 事件计算机器人 QQ、用户 QQ、群号和可见 scope；不采用聊天正文中的“我是管理员”等身份声明。
2. 按当前会话调用 NapCat 历史接口，请求最多 30 条历史，去重后存入本机。历史读取失败时使用已有本机记录。
3. 从当前 scope 读取最近 40 条消息，按时间正序提供给模型；群聊保留发言人 QQ 和名称，可见消息附引用 ID。
4. 在该 scope 最近最多 2000 条未撤回记录中，跳过最近 40 条，以当前文本的双字符片段做词面匹配，取最多 5 条旧消息补充。
5. 读取当前个人状态，例如好感、物品、任务和重要事项，由 `update_status` 技能维护。
6. 显式绑定主人私聊额外检索主人长期记忆集合；本地桌面也可读取该集合。

消息、引用、图片观察结果和工具输出是上下文数据，不改变身份或权限。正常回复只有收到发送成功回执后才记为 assistant；消息段和发送回执也保留。发给机器人自身、通知和请求不触发聊天回复；撤回会替换可见正文，并禁止再次触发回复。

## 可见范围

| 场景 | 对话记忆 | 个人状态 | 共享边界 |
| --- | --- | --- | --- |
| 本机桌面 | `owner` | `owner` | 与显式绑定主人私聊共享 |
| 主人 QQ 私聊 | `owner` | `owner` | 与桌面共享；多个绑定主人共用此空间 |
| 其他 QQ 私聊 | 机器人账号 + 用户 QQ | 同私聊 scope | 不读取主人、其他私聊或群记录 |
| 群聊 | 机器人账号 + 群号 | 群 scope + 用户 QQ | 可读当前群所有发言，个人状态分开 |

同一个 QQ 用户在不同群的个人状态分别保存；群内状态也不与该用户私聊共用。群内主人仍只读取本群公开记录。群角色（群主/管理员）与 Bines 主人绑定分离。

## 当前能力与限制

原始对话持续保存，重启不丢；近期窗口限制只影响每次模型输入，不删除旧记录。词面召回能够找到相近词语，**尚未实现向量语义检索、聊天自动摘要、自动事实提炼或日记归纳**。`start_maintenance_services()` 目前没有运行摘要服务。

长期集合主要来自旧主人 JSON 导入和本机记忆管理。QQ 聊天本身不会自动写入该集合；普通用户长期连续性来自持久化原始记录和个人状态。

未 @ 的群消息也保存为本群背景，可供后续回复参考。OneBot 断线期间不能保证完整回放；历史补取在该会话下一次回复时进行。

事件队列、回复轮次、工具写操作回执也存于同一个数据库，但它们用于去重、恢复和避免重复发送，不直接充当人格记忆。当前没有自动删除保留策略；本机可用按需启动的 RAG Web 查看和管理记录。

关键实现：`chatBot/messages.py` 的 `Identity.scope/state_scope`，`chatBot/store.py` 的 `context/recall/state`，`thingking/qq_thinking.py` 的 `import_history/process`。
